# 参赛流程

[返回目录](../README.md)

以下是规划 HSL 参赛工作的顺序。**每届的材料、时间和平台规定单独核对**；[2026 年 HSL 世界赛](../events/2026/hsl-world-cup.md)可作为已发生届次的例子。

1. **确定目标**：赛事全称、年份、尺寸组别、队伍配置；保存官方参赛通知和正式规则版本。
2. **建立队伍与平台计划**：确认负责人、联系人、机器人来源、可用数量、维护与场地条件。HSL 允许商业或自制人形平台，具体限制看当届规则。[来源：2026 HSL 招募通知](https://hsl.robocup.org/call-for-participation/)。
3. **准备资格申请**：核对在线系统、预申请信息、视频、TDP、软件说明、硬件规格与承诺函。2026 届还要求申请队伍参与其他队伍材料的评审；这类要求不能默认延续到下一届。[来源：2026 HSL 招募通知](https://hsl.robocup.org/call-for-participation/)。
4. **完成资格与正式注册**：资格通过后，按赛事组织方的注册通知办理人员、费用、旅行与设备运输事项；资格通过不等于注册完成。
5. **开发和验收**：按规则逐项验证机器人尺寸、自治能力、比赛通信、起身、行走、找球、踢球等；留下测试日期、设备、日志和未通过项。
6. **现场与赛后**：参加检录、机器人检查、裁判与赛程安排，赛后保留结果、TDP、可公开代码及复盘。

责任人可把每项拆成“要求、来源、截止时间、负责人、完成证据”五列的任务表。临近比赛时再次核对官方公告和[邮件列表](../resources/websites.md)，不要只看早期的招募通知。
