# 学习路线

[返回目录](../README.md)

学习内容应围绕队伍当前任务取舍，不必等所有主题学完才参与项目。

| 阶段 | 建议掌握的内容 | 可验证的结果 |
| --- | --- | --- |
| 基础 | Git、命令行、队伍使用的编程语言 | 能获取代码、运行已有示例并描述结果 |
| 机器人基础 | 坐标系、传感器、执行器、运动学 | 能解释项目中的数据和控制链路 |
| 系统实践 | 队伍的软件框架、通信、仿真与调试 | 能定位一个模块并完成小改动 |
| 比赛任务 | 感知、定位、运动控制、行为决策等实际分工 | 能根据规则和测试结果改进一项功能 |

课程、代码与工具的具体链接放在[仓库索引](../resources/repositories.md)，并注明适用平台。
