# 新人从这里开始

[返回目录](../README.md)

1. 阅读[入门介绍](introduction.md)，确认目标组别和赛事。
2. 在[网站索引](../resources/websites.md)找到该组别的官方规则入口，并核对年份与版本。
3. 向队伍确认实际使用的平台和仓库，再从[仓库索引](../resources/repositories.md)选择材料。
4. 按[首次运行](first-run.md)记录环境、命令和结果。
5. 根据[学习路线](learning.md)补足当前任务需要的知识。

如果还未加入队伍，可以先阅读公开资料；涉及平台和环境的步骤应以目标队伍的实际配置为准。
