# 新人从这里开始

[返回目录](../README.md)

## 尚未加入队伍

1. 读[赛事概览](introduction.md)，确认 HSL 与其他足球组的区别。
2. 从[HSL 官方网站](https://hsl.robocup.org/)进入规则、邮件列表和新队伍说明；阅读规则时先看发布版本，不以仓库 `main` 分支的草稿代替正式规则。
3. 在[2026 队伍名单](https://hsl.robocup.org/qualified-teams/)中挑一支队伍，读其 TDP（队伍技术说明）和软件资料，列出不理解的术语。
4. 按[学习路线](learning.md)完成 Git 和机器人基础，再选一个公开项目做[首次运行](first-run.md)。

## 已加入队伍

先问清目标赛事与组别、机器人型号、负责模块、主仓库与分支、开发环境和测试方式。把这些写成个人任务记录，然后完成最小复现：能获取代码、按项目说明启动一个示例、保存命令与实际输出。后续再读该模块的接口和测试。

## 一周内可以交付的小成果

- 画出“传感器 → 感知/定位 → 决策 → 运动控制”的队伍软件链路，标出自己负责的模块。
- 复现一个公开或队内示例，记录环境、命令、预期与实际结果。
- 找到当届规则中与自己模块有关的一条约束，附规则版本和章节。

比赛报名、资格材料和期限见[参赛流程](participation.md)与[年度赛事资料](../events/README.md)。
